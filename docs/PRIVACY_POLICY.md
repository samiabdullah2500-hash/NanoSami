# NanoSami Privacy Policy (draft)

Effective date: (set on publication) · Contact: (add creator contact on publication)

NanoSami — Materials Science & Nanotechnology Toolkit is designed to work entirely
on your device.

**Data we collect: none.** NanoSami does not collect, transmit, sell or share any
personal data, usage analytics, or advertising identifiers. It contains no
advertising trackers and makes no network requests during normal use.

**Your files.** Spectra and data you import are processed locally in the app's own
environment. They are never uploaded to any server. Imported data are held only in
memory and are discarded when you close or reload the application. To delete
imported data at any time, simply close the app or load a different file.

**Permissions.** The app requests file access only at the moment you choose a file
to import, using the system file picker.

**Children.** The app collects no data from any user, including children.

**Changes.** Any future change to this policy will be published with the app update
and in the project repository before taking effect.
